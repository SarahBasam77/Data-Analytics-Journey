# Obtaining & Investigating Data

## 🔍 Key Questions
- What data do we need?
- What data do we have?
- Is the data clean?

## 🛠 Tools Covered

### Excel
- Best for small datasets
- Skills: cleaning, pivot tables, charts, formulas

### SQL
- For relational databases & big data
- Skills: queries, joins, data retrieval

### Tableau
- Data visualization & dashboards
- Skills: visual analytics, data blending

## 📊 Data Concepts
- **Dataset**: Collection of data
- **Metadata**: Describes the data
- **CSV**: Standard data exchange format

## 🌐 Kaggle
- Data science community
- Datasets, competitions, notebooks
