# Module 2: Obtaining and Investigating Data

**Main Goal:** This module focuses on the practical foundations of the data workflow: **Obtaining** data and **Investigating** (exploring and preparing) it.

## Key Points

### 1. Core Tools for Data Analysis
- **Excel:** Fundamental tool for **small datasets** and **quick analysis**. Used for importing, cleaning, manipulating, summarizing (with **pivot tables**), and visualizing data.
- **SQL (Structured Query Language):** Essential for working with **large datasets** in relational databases. Used to **access, retrieve, manipulate, and analyze** structured data efficiently.
- **Tableau:** Leading **data visualization** tool to create impactful charts and dashboards for **presenting insights** to non-technical stakeholders.

### 2. Fundamental Questions & Data Basics
- **Three Key Questions:** What data do we **need**? What data do we **have**? Is the data **clean**?
- **Dataset:** A collection of data; can be **private** or **publicly available** (e.g., CSV files from sources like WHO or Kaggle).
- **Metadata:** The **"data about data"** that describes the contents and structure of a dataset. It is the analyst's essential guide.

### 3. Foundational Data Concepts (Gathering Data)
- **Variable:** A **characteristic or attribute** being measured (e.g., breed, weight). It's a **column** in a dataset.
- **Observation:** A **single record or instance** containing values for all variables. It's a **row** in a dataset.
- **Value/Data Point:** The **specific measurement** for a variable in an observation (e.g., "15 kg"). It's a **cell** in a dataset.
- **Purpose-Driven Data:** The data you collect and keep **must be directly relevant** to your analysis goal.

### 4. Types of Variables (Critical for Analysis)
- **Categorical:** Represents **group membership** (qualitative).
  - **Nominal:** Categories with **no order** (e.g., color, gender).
  - **Ordinal:** Categories where **order matters** but intervals aren't defined (e.g., satisfaction level).
- **Numerical:** Represents **quantifiable amounts** (quantitative).
  - **Discrete:** **Countable** items (e.g., number of visits).
  - **Continuous:** **Measurable** quantities that can take any value in a range (e.g., weight, temperature).
- **Importance:** The variable type **dictates** the correct statistical tests and data visualizations (e.g., bar charts for categorical data, scatter plots for numerical relationships).

### 5. Key Resource: Kaggle
- **Kaggle** is an essential online **community and platform** for data professionals. It provides:
  - Publicly available **datasets** (CSV files, images, etc.).
  - Code sharing, competitions, and courses.
  - A place to find inspiration and discuss data science projects.

- Creating charts and visualizations
- Summarizing data with **pivot tables**

### SQL:
- Creating tables
- Retrieving data using indexes and queries
- Aggregating data with joins

### Tableau:
- Creating visualizations
- Comparing data using **dashboards**

## Highlighted Takeaway
Module 2 builds the **practical foundation** for data work. It moves from understanding **what data is** (variables, observations) and **where to get it** (Kaggle, public sources), to mastering the **first crucial tools** (Excel, SQL, Tableau) needed to **obtain, investigate, clean, and initially visualize** data—setting the stage for deeper analysis.
