# Tableau Dashboard
Dashboards can feature either static data (point-in-time snapshots, which lose relevance over time) or live data (automatically updated for real-time insights and action).

## Benefits of dashboards include:
- Consolidating data from multiple sources into a single screen.
- Providing a dynamic, user-friendly interface.
- Enabling interactive features like filtering, zooming, and detailed analysis.

## Best practices for dashboard creation:
- Understand your audience's needs.
- Present clean, relevant data.
- Choose appropriate visualizations.
- Use templates to save time.
- Avoid clutter and excessive colors.
- Incorporate feedback to refine the design.

## Creating a dashboard in Tableau:

1. Click the "New Dashboard" icon (next to "New Worksheet").
2. Drag sheets from the left panel into the center workspace to add visualizations.
   - There is no limit to the number of views you can add.
   - Dashboards remain linked to their source worksheets, so changes in either are synchronized.
   - Dashboards allow all relevant information to be displayed on one screen, eliminating the need for navigation across multiple tabs.
